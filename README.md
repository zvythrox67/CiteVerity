# CiteVerity

CiteVerity is a web application designed to help users determine the legitimacy of online information. By pasting a URL into the dashboard, the app analyzes the page's code, text, and outbound network to determine if it is a credible source, or misinformation.

## How the Scoring Works

Every page starts with a perfect **100% Trust Score**. The backend runs the page through five specialized modules (called Detectives) that look for specific red flags and deduct points based on a strict penalty system. 

The final score is calculated using this formula:
`Final Score = Max(0, 100 - Total Penalties)`

The score will never drop below 0%. The final score is color-coded:
*   **85% to 100% (Green):** High Trust. Transparent author, links to primary data, and verifiable citations.
*   **50% to 84% (Yellow):** Caution. The source might be real, but it has flaws like missing authors, biased language, or a lack of primary sources.
*   **0% to 49% (Red):** Untrustworthy. The system detected severe fraud, such as fake AI citations, circular reporting, or repurposed images.

## The 5 Detectives (How Points are Deducted)

**1. Identity & Date Checker (Category A)**
*   **Anonymous Author (-15 points):** The app scans the HTML for an author. If there is no name, or if it finds a generic name like "Admin," it deducts points.
*   **Suspicious Domain (-20 points):** It checks the domain age via ICANN WHOIS. If the site was registered a few days ago, or uses scam-heavy endings like .xyz or .biz, it deducts points.
*   **Old Story Re-packaging (-15 points):** It checks the URL and the Wayback Machine. If a story claims to be from 2024 but the URL or archive history shows it is from 2018, it catches it.

**2. Source Tracker (Category B)**
*   **No Outbound Evidence (-30 points):** The heaviest penalty. If an article makes big claims but has zero hyperlinks backing them up, or relies on vague phrases like "experts say," it loses points.
*   **Dead-End Evidence Trail (-15 points):** If the article links out, but only links to other opinion blogs instead of official sources (like .gov, .edu, or DOI databases), it loses points.
*   **Non-Falsifiable Rhetoric (-10 points):** It scans for hard data. If the text has almost zero numbers, dates, or testable statistics, it is flagged as pure opinion.

**3. Fact & Rumor Scanner (Category C)**
*   **Circular Reporting Loop (-25 points):** Using the NetworkX library, it builds a directed graph of the websites this page links to. If Website A quotes Website B, and Website B quotes Website A without a primary source, it catches the loop.
*   **Unverifiable / Fake Citations (-30 points):** It extracts in-text citations (e.g., Smith, 2022) and checks the Crossref academic database. If the cited study or DOI does not actually exist (a common AI hallucination), it deducts massive points.

**4. Mind-Games & AI Catcher (Category D)**
*   **High Emotional Urgency (-15 points):** It scans for clickbait and manipulation. Phrases like "Share this before it's deleted!" or "The secret they hid from you!" trigger point deductions.
*   **AI Writing Test:** It calculates the uniformity of the sentences to guess if the text was generated by an AI.

**5. Image Matcher (Category D)**
*   **Decontextualized Image (-20 points):** It fingerprints the photos on the page and checks the Wayback Machine. If a story claims a photo is from a current event, but the exact same photo was used in an article from ten years ago, it flags it as fake evidence.
